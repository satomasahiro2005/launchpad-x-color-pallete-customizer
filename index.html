Help — getting the firmware & palette format

Get the firmware (.syx)

This app does not bundle firmware — load your own. Connect the Launchpad X in bootloader mode (hold Capture MIDI while plugging in), open Novation Components, start a firmware reinstall, then find the firmware URL in DevTools → Network. It looks like:

https://circuit-librarian.s3.eu-west-1.amazonaws.com/uploads/firmware/file/147/launchpadx-firmware-422.syx

Download that file, then press Load firmware above. Decoded official v2.0.1 is detected by its SHA-256.

Palette file format (Import / Export)

Plain text, one entry per line: index, R G B; — index 0–127, each channel 0–63. All 128 entries required. Example:

0, 0 0 0; 5, 63 0 0; 21, 0 63 0;

Ready-made Launchpad palettes: kaskobi.com/palettes.
