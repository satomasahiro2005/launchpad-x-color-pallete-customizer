Connect the Launchpad X in bootloader mode, open components.novationmusic.com, start a firmware reinstall, then use DevTools Network to find the official firmware URL. It should look like https://circuit-librarian.s3.eu-west-1.amazonaws.com/uploads/firmware/file/147/launchpadx-firmware-422.syx. Download that SYX file and load it here.

This app does not include firmware. It only checks the official 422 SHA-256 hash.
