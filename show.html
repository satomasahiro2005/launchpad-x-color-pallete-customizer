Shows the palette on the Launchpad X Session tab via DAW mode (no Programmer mode, so the device stays usable). Each pad is lit by palette index, so it shows the device's palette colours — 8×8 per page. Send to the DAW port; detection may miss a Launchpad, so all MIDI outputs are listed. "Exit DAW mode" reverts to Standalone.
